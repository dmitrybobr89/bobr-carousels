# Карусели Дмитрия Бобра: материалы для облачной сессии

Здесь нет ключей, токенов и паролей: только скрипт вёрстки, шрифты, значки и готовые слайды. Ничего секретного сюда не добавлять.

Правила: пиши по-русски; без слов «курс, обучаю, учу, уроки» про услуги Дмитрия; консультация: «системный разбор, в личных сообщениях @Dmitry_Bobr»; без выдуманных цифр; примеры помечай «(пример)». Стиль слайда: тёмный фон с зерном, узкий жирный заголовок (Bebas Neue), ключевая фраза на жёлтой плашке, вставка показывает мысль, поля 100 px, у краёв ничего.

Скрипт `make_carousel_silnee.py` собирает слайды 2–9 (обложка сделана отдельно). Пути в нём указывают на Mac Дмитрия (/Users/dmitry/...): в облаке заменить на пути репозитория.
Картинки в Gemini генерируются только на Mac Дмитрия, в облаке не делаются.
